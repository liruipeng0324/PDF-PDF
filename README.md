# PDF-PDF 双层 PDF 制作工具

这是一个本地网页工具，用来制作“双层 PDF”：页面外观来自原文档渲染出的图片，底层加入 OCR 文字层，最后把原 PDF 的书签恢复到最终 PDF。

详细安装和使用步骤请看：

[`使用说明.md`](./使用说明.md)

## 快速启动

双击：

```text
start-web.bat
```

浏览器打开后，选择输入文件或输入文件夹，再选择输出目录，点击“开始制作”。

## 主要功能

- 单个 Word / PDF 制作。
- 文件夹队列制作。
- CSV 队列制作。
- Windows 原生文件/目录选择。
- 实时显示队列子任务日志。
- PNG 页数、OCR 页数进度显示。
- 取消任务时停止当前子进程。
- 依赖检测、缓存清理、查看最近输出。

## 注意

直接处理 Word 文件需要安装 Microsoft Word。没有 Word 时，请先手动把 Word 导出为带书签 PDF，再使用“已导出的带书签 PDF”模式。
