# PDF-PDF 图片版 PDF 制作工具

这是一个本地网页工具，用来把 Word 或带书签 PDF 转成图片版 PDF，并把原 PDF 的书签恢复到最终文件。

详细安装和使用步骤请看：

[`使用说明.md`](./使用说明.md)

## 快速启动

双击：

```text
start-web.bat
```

浏览器打开后，选择输入文件或多个队列文件，再选择输出目录，点击“开始制作”。

## 主要功能

- 单个 Word / PDF 制作。
- 多文件队列制作。
- CSV 队列制作。
- Windows 原生文件/目录选择。
- 图片页数进度显示。
- 恢复原 PDF 书签。
- 可选压缩优化。
- 缓存清理、依赖检测、最近输出查看。

## 注意

直接处理 Word 文件需要安装 Microsoft Word。没有 Word 时，请先手动把 Word 导出为带书签 PDF，再使用“已导出的带书签 PDF”模式。
